IMPORTANT: Build the ENTIRE website in one pass from this specification. Do not create a basic template or a generic AI dashboard. The website must feel like a professionally designed real-world environmental technology product that could be presented as a final-year BCA project.

==================================================

1. CORE PROJECT IDEA
   ==================================================

GreenGuard is an intelligent environmental monitoring platform designed to help detect and document suspected tree-cutting activity.

The platform allows users to:

1. Upload an image or video.
2. Analyze the media using a computer-vision detection system.
3. Detect relevant objects such as trees, people, chainsaws, stumps, timber/logs, and possible cutting activity.
4. Display detection results with confidence scores.
5. Generate a risk assessment.
6. Add incident location.
7. Create an environmental incident report.
8. Track submitted reports.
9. View incidents on an interactive map.
10. Allow administrators to review and update incidents.

The purpose is NOT to automatically accuse anyone of illegal activity.

Always use wording such as:

"Possible Tree-Cutting Activity Detected"

rather than:

"This person is illegally cutting trees."

Include a disclaimer that AI results require human verification.
